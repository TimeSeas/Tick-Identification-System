## 一、没有实习怎么办

### 现状判断
大四上学期（2026 秋）仍在**日常实习窗口**内（实习僧/Boss 直聘的日常实习全年招），同时秋招 9-12 月进行中。正确姿势是**并行**：秋招为主，实习为辅——拿实习 Offer 也可作秋招背书。

### 四条破局路径（按性价比）

1. **把毕设项目当实习用（最强武器）**：你的蜱虫系统有完整工程闭环（数据→训练→级联系统→Docker 部署），很多实习生的产出不如它完整。补齐最后一步让它"像产品"：**部署成公网可访问的 Demo**（服务器或内网穿透），简历附链接，面试现场打开演示——这是无实习者最有说服力的替代证明
2. **GitHub 持续提交**：把项目推到 GitHub（现有 TimeSeas 账号），README 写清架构图与指标，持续 commit 形成贡献热力图。面试官真的会看
3. **投中小厂/外包实习岗**：佛山本地软件公司、广州 AI 创业公司、外包大厂的实习岗门槛低且常年缺人；AI 创业公司尤其看项目不看学历，你的 RAG/Agent 技能正是他们想要的
4. **实习转正通道**：投递时选择"可转正实习"岗位，把实习当秋招的另一条路

## 二、简历技术栈"不精通"怎么处理

### 三档处理法（逐项过简历）

| 档位 | 判断标准 | 处理 |
|------|---------|------|
| **真会** | 项目里亲手用过、能讲清原理和踩过的坑 | 保留，措辞"熟练" |
| **半会** | 用过但只到 API 层面，讲不深 | 二选一：降级措辞为"了解"；或花 1 天补原理准备三层追问 |
| **不会** | 只跑过教程/听说过 | **删掉**。一个被追问穿帮的词，会让面试官质疑整份简历 |

### 你的简历逐项处理建议（示例）

| 简历原词 | 档位自评 | 建议 |
|----------|---------|------|
| PyTorch/ResNet/Mask R-CNN | 真会（项目深度用） | 保留"熟练"，备好三层追问（见下） |
| Docker/Nginx 部署 | 真会（亲手部署过） | 保留，重点讲容器字体坑/卷挂载/多阶段构建 |
| Spring Boot 3/MySQL | 半会→真会（项目用过） | 保留"熟练"，补索引优化与事务隔离级别八股 |
| LangChain/LlamaIndex/RAG | 半会 | 保留但降为"熟悉"，准备 RAG 全流程追问（召回为什么差→重排序怎么选） |
| LoRA/QLoRA 微调 | 半会/不会 | 若没真跑过微调 → 降为"了解 LoRA 原理"或删 |
| vLLM/TensorRT/Triton | 不会（只了解概念） | **删或标"了解"**——这三个是深度坑，应届生被问必穿 |
| K8s | 了解 | 保留"了解 Pod/Service 概念"，别写"熟悉" |
| 鸿蒙 ArkTS | 半会（项目用过） | 保留，投润和/鸿蒙生态岗位时重点讲 |
| Three.js | 配合项目用的 | 保留"配合 Vue3 使用"，别独立写"掌握" |

### 通用规则
- 应届生最高措辞 = "熟练掌握"；**永远不写"精通"**
- 每个技能必须能在 5 秒内对应到某个项目的某段代码
- 简历一页半以内，删掉凑数的技能比堆砌更可信

## 三、面试怎么准备（1-2 周冲刺版）

### 三层追问法：给简历每个技能准备三题

```
L1 是什么：ResNet 是什么？Mask R-CNN 两阶段指什么？
L2 怎么用：你的项目里怎么微调的？数据多少、batch、lr、精度多少？
L3 为什么：为什么检测-分类要级联而不是一个模型？为什么用 448 而不是 224？
```

你的蜱虫项目天然自带十几个 L3 级好答案（级联取舍、数据质量论、阈值方法、切块推理、容器化踩坑）——**把项目讲稿写成 10 分钟版本反复练**，这是你所有面试里最硬的素材。

### 八股按主攻方向选一档猛补

| 主攻方向 | 必补八股 | 参考量 |
|----------|---------|--------|
| AI 应用岗 | ML/DL 基础（过拟合/正则/损失函数）、Transformer 原理、RAG 全链路、LangChain 概念 | 50 题 |
| Java 后端岗 | Java 集合/并发/JVM、Spring IOC/AOP、MySQL 索引/事务、Redis | 100 题 |
| 通用必背 | 网络（TCP/HTTP）、操作系统（进程线程）、数据结构 | 50 题 |

### 算法题（秋招硬通货）
LeetCode：先简单 50 题建立信心 → 高频中等 100 题（链表/树/哈希/双指针/DP 入门）。每天 2-3 题，面试前突击高频 50 题。

### 实战反馈循环（最重要的技巧）
每次面试后立刻记录被问的问题 → 分三类（项目追问/八股/算法）→ 当天补盲点。面 3-5 场后，你会发现题目高度重复——**面试是最好的复习提纲**。
