## 2. 可直接引用的实验数据

### 2.1 检测基线（M1）
- 模型：torchvision Mask R-CNN + ResNet-50-FPN，COCO 预训练
- 数据集：`ticks image detection.v5i.coco`（train 1136 / valid 332 / test 134）
- 指标：单类 mAP@0.50 = 0.842（pycocotools COCOeval）

### 2.2 SAM 标注方法学（创新点 ①）
- **box 提示范式**：1649/1649 生成成功，单框提示置信度实测 0.92–0.95；bbox 与掩码多边形逐条一致（0 异常）
- **AMG 无提示范式**：7 类试点 210 图 / 652 掩码；人工抽查结论为"复杂场景效果不理想"（误分割/漏检/类别缺失）
- **核心结论**（论文论点）：提示强度决定任务难度——box 携带位置+尺度+语义先验，AMG 是无先验显著性搜索；SAM 类别无关，文件夹名赋类是外部假设
- 原理与完整分析见同目录 `SAM自动标注原理与效果分析.md`

### 2.3 蜱种数据集建设（数据章节素材）
- 规模：173 物种 8055 张（1024px JPEG，约 1.4GB）
- 三来源（均可写"数据来源与方法"）：
  1. GBIF 3 个 DOI 归档（TickIDNet 论文出处）→ 3 物种 2462 张
  2. GBIF API 按物种名检索 → 12 物种（含长角血蜱、全沟硬蜱、血红扇头蜱等中国常见种）
  3. HuggingFace fine-grained-challenges 的 Ixodidae 组（CC0）→ 4499 张
- 长尾分布：31 物种 ≥50 张（共 6171 张）；82 物种 <10 张（保留作 zero-shot 素材）
- 工程方法（可写一节）：static.inaturalist.org 在国内网络 403 → 官方 Open Data S3 桶镜像；GBIF 免登录 API；lance 格式解包

### 2.4 3 类分类实验（与 TickIDNet 论文对照）
- 设置：ResNet-50（ImageNet 预训练）微调，Adam lr 1e-4 + 余弦退火，20 epochs，8:1:1 分层划分（train 2209 / val 277 / test 276）
- **测试集准确率 89.5%，F1 89.1%**；混淆矩阵见 `output/tick_species_3_results/confusion_matrix.png`
- 分物种正确率与 TickIDNet 基线对比（⚠️ 论文须注明：数据划分与评估集不同，为参考对照）：

| 物种 | 本文（3 类） | TickIDNet 报告 |
|------|-------------|----------------|
| 犬蜱 D. variabilis | 90.9% | 91.36% |
| 黑腿蜱 I. scapularis | **93.8%** | 86.91% |
| 孤星蜱 A. americanum | **81.0%** | 77.84% |

### 2.5 31 类分类实验
- 设置：加权采样（类频率倒数）+ 标签平滑 0.1，其余同上；train 4939 / val 616 / test 616
- 结果：best val_f1 0.701（epoch 17），test acc 65.9%，test F1 0.641
- **过拟合现象**（可写"讨论"）：train_acc 99.3% vs val_acc 69.5%，gap ≈ 30 点——小类样本不足的典型表现
- **反直觉发现**（可写"讨论"）：孤星蜱无阈值正确率从 3 类模型的 79.0% 升至 31 类模型的 87.1%——类别增多迫使模型学习更细粒度的判别特征

### 2.6 分物种置信阈值（复现 Villon et al. 2020）
- 方法：tau ∈ [30,100] 千点扫描，约束误分类率 MC < 上界（10%/5%/2%），最大化正确率；低于阈值判"不确定"
- 3 类模型 MC<2% 结果：

| 物种 | 阈值 | 正确率 | 转不确定比例 | 排除不确定后准确率 |
|------|------|--------|-------------|-------------------|
| 孤星蜱 | 99.9 | 41.9% | 58.1% | 100% |
| 犬蜱 | 99.4 | 60.2% | 39.1% | 98.8% |
| 黑腿蜱 | 99.8 | 46.3% | 51.2% | 95.0% |

- 31 类阈值表：`output/tick_species_31_weighted/thresholds.csv`（多数类排除不确定后 95-100%）
- 医学意义论点："宁可不答，不要猜错"——风险评估场景下 uncertain 输出比高置信误判更安全

## 4. 可写的发现与讨论点（论文加分线索）

1. **提示强度决定自动标注质量**：box 提示 0 失败 vs AMG 复杂场景失效——方法学章节的核心论点
2. **级联架构依据**：检测-分类级联是细粒度识别标准范式，本文三模型架构的实证（3 类 vs 31 类实验支撑）
3. **细粒度训练中的反直觉现象**：类别数增加反而提升单类判别力（孤星蜱 79.0% → 87.1%）
4. **长尾处理有效性**：加权采样 vs 无加权基线的消融（待跑，预期论文对照实验）
5. **分物种阈值的医学价值**：不确定输出机制在风险提示系统中的应用
6. **公开生态数据构建医学影像数据集的工程方法**：GBIF/iNaturalist/HF 三源合并、403 镜像问题、许可合规
