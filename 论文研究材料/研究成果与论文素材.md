## 2. 可直接引用的实验数据

### 2.1 检测基线（M1）
- 模型：torchvision Mask R-CNN + ResNet-50-FPN，COCO 预训练
- 数据集：`ticks image detection.v5i.coco`（train 1136 / valid 332 / test 134）
- v1：mAP@0.50 = 0.842（pycocotools COCOeval，训练于 SAM 补全前）
- **v2（2026-09-11）**：mAP@0.50 = **0.857**（1024 输入分辨率 + 翻转/色彩增强 + 掩码多边形支持修复；训练 10/15 轮因系统内存尖峰中断，检查点即用）。对比 v1 +1.4 点
- 修正记录：evaluate_model.py 的 COCOeval.stats 索引此前标注错位（stats[0]=mAP@[.5:.95]、stats[1]=mAP@.5、stats[2]=mAP@.75），已修正——此前报告的 0.842 实为 stats[1] 即真实 mAP@0.50，口径一致

### 2.2 SAM 标注方法学（创新点 ①）
- **box 提示范式**：1649/1649 生成成功，单框提示置信度实测 0.92–0.95；bbox 与掩码多边形逐条一致（0 异常）
- **AMG 无提示范式**：7 类试点 210 图 / 652 掩码；人工抽查结论为"复杂场景效果不理想"（误分割/漏检/类别缺失）
- **核心结论**（论文论点）：提示强度决定任务难度——box 携带位置+尺度+语义先验，AMG 是无先验显著性搜索；SAM 类别无关，文件夹名赋类是外部假设
- 原理与完整分析见同目录 `SAM自动标注原理与效果分析.md`

### 2.3 蜱种数据集建设（数据章节素材）
- 规模：173 物种 8055 张（1024px JPEG，约 1.4GB）
- 三来源（均可写"数据来源与方法"）：
  1. GBIF 3 个 DOI 归档（TickIDNet 论文出处）→ 3 物种 2462 张
  2. GBIF API 按物种名检索 → 12 物种（含长角血蜱、全沟硬蜱、血红扇头蜱等中国常见种）
  3. HuggingFace fine-grained-challenges 的 Ixodidae 组（CC0）→ 4499 张
- 长尾分布：31 物种 ≥50 张（共 6171 张）；82 物种 <10 张（保留作 zero-shot 素材）
- 工程方法（可写一节）：static.inaturalist.org 在国内网络 403 → 官方 Open Data S3 桶镜像；GBIF 免登录 API；lance 格式解包

### 2.4 3 类分类实验（与 TickIDNet 论文对照）
- 设置：ResNet-50（ImageNet 预训练）微调，Adam lr 1e-4 + 余弦退火，20 epochs，8:1:1 分层划分（train 2209 / val 277 / test 276）
- **测试集准确率 89.5%，F1 89.1%**；混淆矩阵见 `output/tick_species_3_results/confusion_matrix.png`
- 分物种正确率与 TickIDNet 基线对比（⚠️ 论文须注明：数据划分与评估集不同，为参考对照）：

| 物种 | 本文（3 类） | TickIDNet 报告 |
|------|-------------|----------------|
| 犬蜱 D. variabilis | 90.9% | 91.36% |
| 黑腿蜱 I. scapularis | **93.8%** | 86.91% |
| 孤星蜱 A. americanum | **81.0%** | 77.84% |

### 2.5 31 类分类实验
- 设置：加权采样（类频率倒数）+ 标签平滑 0.1，其余同上；train 4939 / val 616 / test 616
- 结果：best val_f1 0.701（epoch 17），test acc 65.9%，test F1 0.641
- **过拟合现象**（可写"讨论"）：train_acc 99.3% vs val_acc 69.5%，gap ≈ 30 点——小类样本不足的典型表现
- **反直觉发现**（可写"讨论"）：孤星蜱无阈值正确率从 3 类模型的 79.0% 升至 31 类模型的 87.1%——类别增多迫使模型学习更细粒度的判别特征

### 2.6 分物种置信阈值（复现 Villon et al. 2020）
- 方法：tau ∈ [30,100] 千点扫描，约束误分类率 MC < 上界（10%/5%/2%），最大化正确率；低于阈值判"不确定"
- 3 类模型 MC<2% 结果：

| 物种 | 阈值 | 正确率 | 转不确定比例 | 排除不确定后准确率 |
|------|------|--------|-------------|-------------------|
| 孤星蜱 | 99.9 | 41.9% | 58.1% | 100% |
| 犬蜱 | 99.4 | 60.2% | 39.1% | 98.8% |
| 黑腿蜱 | 99.8 | 46.3% | 51.2% | 95.0% |

- 31 类阈值表：`output/tick_species_31_weighted/thresholds.csv`（多数类排除不确定后 95-100%）
- 医学意义论点："宁可不答，不要猜错"——风险评估场景下 uncertain 输出比高置信误判更安全

## 4. 可写的发现与讨论点（论文加分线索）

1. **提示强度决定自动标注质量**：box 提示 0 失败 vs AMG 复杂场景失效——方法学章节的核心论点
2. **级联架构依据**：检测-分类级联是细粒度识别标准范式，本文三模型架构的实证（3 类 vs 31 类实验支撑）
3. **细粒度训练中的反直觉现象**：类别数增加反而提升单类判别力（孤星蜱 79.0% → 87.1%）
4. **长尾处理有效性**：加权采样 vs 无加权基线的消融（待跑，预期论文对照实验）
5. **分物种阈值的医学价值**：不确定输出机制在风险提示系统中的应用
6. **公开生态数据构建医学影像数据集的工程方法**：GBIF/iNaturalist/HF 三源合并、403 镜像问题、许可合规

## 4.5 问题诊断与数据清洗方案（2026-09-11 新增，论文"数据预处理"章节素材）

### 诊断：31 类模型精度受限的根源在数据质量

实测现象：大量测试图被判"不确定"；训练集（三源下载）存在三类噪声：
1. **非蜱图**：iNaturalist 记录混有非蜱照片（错误鉴定/背景图）——训练时被强制标成某物种 = 标签噪声
2. **质量参差**：模糊图、极小目标图、多虫混居图——特征不可靠
3. **长尾失衡**：50~1325 张/类——大头类梯度挤压小类

**因果链**：脏数据 → 特征空间混入噪声 → 置信度整体压低 → 大量样本落于分物种阈值之下 → "不确定"频发。此现象与分物种阈值机制交互：阈值越严，脏数据的影响越被放大。

### 清洗方案：检测模型辅助清洗（方法学小亮点）

利用现有蜱虫检测模型（mAP 0.842）对全部 8055 张训练图批量推理，**只剔除真噪声、保留难样本**：

| 检测结果 | 处置 | 理由 |
|----------|------|------|
| **零检出**（检不出蜱虫） | 人工复核后**删除** | 疑似非蜱图/坏图 = 标签噪声主源 |
| **多虫同框** | **保留**（报告标记为多虫样本） | 真实用户上传常含多虫；系统必须健壮，不能只学单虫标准照 |
| **小目标** | **保留**（报告标记为小目标样本） | 推理时分类器输入就是检测框裁剪（小框=低分辨率裁剪），小目标图恰好模拟真实推理输入分布 |
| 单检出+正常 | 保留 | — |

**深层方法论洞察（训练-推理分布一致性）**：当前分类器用整图训练、但推理输入是检测框裁剪——两者分布不一致（train-serve skew）是精度受限的另一原因。进阶方案：**用检测模型把所有训练图裁剪出 ROI，分类器直接用 ROI 训练**——届时多虫图从"标签模糊的整图"变成"每框一只蜱的黄金样本"，训练/推理分布完全对齐，这是下一轮实验的设计方向。

预期效果：剔除零检出噪声 → 重新划分 + 448 分辨率 + 加权采样重训，目标 test F1 0.75+。

### 论文写法
"数据预处理"小节：三源数据集的噪声类型分析（**区分"真噪声"与"难样本"，体现数据治理思想**）→ 检测辅助清洗流程 → 清洗前后样本量对比表 → **清洗前后模型精度对比实验**；"讨论"节写训练-推理分布一致性问题与 ROI 训练方案。

## 4.6 基线对比实验（2026-09-11，数据质量论的量化核心）

### 实验一：测试集噪声对指标的影响
同一旧模型、同一评估脚本（`scripts/eval_species_model.py`），仅换测试集：
- 旧测试集（split_31cls，含噪声图）→ acc 65.9% / F1 0.641
- 清洗后测试集（split_clean）→ 表面 acc 87.78% / macro-F1 0.897

**⚠️ 方法论纠错（论文必须如实写）**：87.78% 存在**训练-测试数据泄漏**——旧划分的训练集与清洗后测试集有约 80% 图片重叠，旧模型"背"过考题，该数字不可作为公平基线。这正是"重新划分后必须重训对照模型"的教训，可作为论文方法学小节的反面案例。

### 实验二：受控消融矩阵（无泄漏，同一干净测试集）

| 配置 | 训练集 | 输入 | test acc | test F1 | 意义 |
|------|--------|------|----------|---------|------|
| A 旧基线 | 未清洗 31 类 | 224 | 65.9%（旧测试集，含噪声） | 0.641 | 起点 |
| B 对照 | **清洗 28 类** | 224 | 67.23% | 0.659 | 隔离"清洗"效应 |
| C 主力 | **清洗 28 类** | **448** | **75.55%** | **0.742** | 当前最优 |

**同测试集严格对照（B vs C）**：448 分辨率带来 **+8.3 点 F1**——细粒度识别中高分辨率是最大单因素收益，实证支持"盾板花纹等微特征需要 448 像素才能保留"的假设。
**训练侧清洗效应（A vs B，口径有差异需注明）**：+1.8 点 F1（且 B 剔除了 3 个噪声大类）。清洗的更大学术价值在实验一（测量修正）而非训练增益——如实写，体现严谨。

### 论文价值
- 数据质量影响的两面：脏**测试集**使指标低估约 20 点（实验一）；脏**训练集**的剔除与分辨率提升带来净增益（实验二）
- 反面案例：跨划分评估的数据泄漏（87.78% 假象）→ 方法学严谨性讨论
