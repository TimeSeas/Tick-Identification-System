# 识别重建维护要点

2026-10-24用户指出现有识别效果仍差，因此不能把上一轮召回增加当成用户需求已经满足。

1. 实际效果应同时检查误检、漏检和正确蜱种；界面、置信阈值和正样本子集的高接受准确率不能证明开放场景效果。
2. 图像增强必须同步框与掩码。训练成功退出并不证明标签位置正确，必须用可定位的合成样例测试几何关系。
3. 路径没有交集或字节哈希不同，仍可能是同一照片不同尺寸或同一观察记录；数据隔离必须跨所有任务和原图/裁剪。
4. 旧任务权重可能已见新的验证分组。重新声称有效验证时应从通用预训练开始，并注明旧基线是否见过比较样本。
5. 来源文件夹是代理标签，空COCO标注也不是人工确认的非蜱虫。训练和验收均应保存这一不确定性，不把模型自判当新真值。
6. 分支文档不写入原项目论文材料。阶段记录、当前上下文和原始日志职责分开；后台训练开始不等于完成。
