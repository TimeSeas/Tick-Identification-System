# Codex优化实践分支文档

适用分支：`codex/practice-report-frontend`。这是分支计划、当前状态、实验和交接的唯一维护入口。当前默认是2026-10-27保守补充识别：保持原确认与检测框，用专项模型补充待确认，未知误确认仍未解决。原项目文档、毕业设计与论文材料不自动采用本分支结论；不修改或合并主分支。

## 接手阅读顺序

1. [分支维护约定](AGENTS.md)：授权、修改范围、训练和证据规则。
2. [当前上下文](CONTEXT.md)：当前需求、进度、文件归属、下一步与未解决事项。
3. [识别重建需求](plans/recognition_rebuild_20261024.md)和[当前蜱种专项计划](plans/species_specialist_20261027.md)：验收目标、失败证据与实施顺序。
4. [历史索引](HISTORY.md)与[版本清单](VERSIONS.json)：此前工作及文档来源。
5. [运行和部署](operations/deployment.md)：使用分支时的配置入口；变更模型后必须同步此处。

## 目录职责

| 位置 | 内容 | 维护方式 |
|---|---|---|
| CONTEXT.md | 当前状态及明确下一步 | 持续改写，过期状态移入历史 |
| HISTORY.md | 用户决策、版本和阶段事件 | 按日期及事件编号追加，不把未完成写成完成 |
| plans/ | 有日期的需求和修改计划 | 当前计划在上下文中唯一指定；新方案不覆盖旧方案 |
| history/<日期>/ | 第一轮记录及阶段上下文快照 | 历史归档，不能作为当前运行状态 |
| experiments/ | 实验登记、数据/模型版本、结果摘要 | 训练前登记，结束后补结果和失败，不只记最佳结果 |
| operations/ | 本分支运行、模型切换、验证与回滚 | 与当前代码同步 |
| baseline/ | 隔离前文档及25427928参考快照 | 保持原文，不继续追加开发内容 |

大体积原始日志、预测、数据清单和模型仍在Git忽略的 `output/optimization_20261015/`；历史重建在 `rebuild_20261024/`，当前蜱种专项在 `species_20261027/`。实验登记必须指向这些真实产物，并记录哈希。文档隔离不等于训练数据隔离，后者仍须单独校验。

## 历史指标解释

2026-10-15记录属于当时划分上的实验。2026-10-24发现来源照片/观测跨集合、冲突标签及跨任务重用，因此旧指标不能再被表述为已经证明无泄漏的端到端泛化。新训练和完整开发对照已产生，部分候选降低误报但损失来源检出，采用状态与局限详见当前上下文；不能把开发验证当独立测试。
