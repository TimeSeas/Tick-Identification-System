# 识别效果重建需求与修改计划

制定日期：2026-10-24。起点为 `codex/practice-report-frontend` 的 `dbf87bc1`。用户授权此分支进行架构修改和重新训练；主分支不改动、不合并。原权重、原划分、历史证据及用户已有未提交文件保留。

## 用户需求

用户认为检测、蜱种和其他昆虫识别均明显不理想，要求在真实图像上获得肉眼可见的改善，而不是仅调整阈值或把错误结果隐藏成待确认。用户指定只使用项目内已有数据，不另外等待用户提供照片。

应回答三个问题：图中是否确有蜱虫；数量和位置是否正确；每个可辨识目标属于哪个已支持蜱种。其他虫不应被轻易计为蜱虫；模糊、过小及不支持的物种需要如实保留识别边界。页面展示从属于模型效果，不作为效果提高的替代证据。

## 已发现的根因和证据

1. 检测训练 Dataset 仅对图像执行 RandomHorizontalFlip，没有同步处理真值框和掩码。这是训练正确性错误；是否及多大程度影响现役v3，须结合实际训练记录核实，不能单凭当前脚本断言。
2. 当前检测训练1715图中仅42张空标注，空标注也未必为经核验真负例；缺少有记录的专项困难负例训练。昆虫分类训练8340张中tick仅97张，不能用整体94%以上准确率代替蜱虫识别效果。
3. 分类训练主要采用整图随机裁剪，部署使用检测区域。上一轮区域融合缓解了差异，但没有重训，也未建立真正的非蜱虫识别能力。
4. 审计发现同字节重复、相同来源照片不同尺寸版本跨集合、跨物种标签冲突；检测训练还包含部分历史蜱种验证/测试图片。因此旧报告的测试指标不能证明无泄漏的端到端泛化。完整计数以本轮审计JSON为准。

审计及模型产物保存在忽略目录 `output/optimization_20261015/rebuild_20261024/`。应用代码更改应在本计划制定后开展。

## 实施顺序与停止条件

### 第一阶段 训练正确性和数据边界

- 为检测图像、boxes、masks执行一致的几何增强，增加可证明框和掩码位置正确的回归；空目标仍须合法。修正训练只验证一个batch或吞异常继续的问题，训练失败必须能定位。
- 按文件摘要、来源photo/observation ID分组去重；冲突标签先隔离，不由现役模型自动改成其预测类别。原文件不删除。
- 固定本轮训练、验证和验收名单及哈希；全任务交叉检查，不能只在单个分类数据集内去重。已有历史测试不再用于反复挑参数。
- 优先从未纳入既有划分的本地材料提取验收候选，并检查与全部训练源的重复。若不能证明对旧模型完全未见，明确标为回顾对照，不伪称全新独立测试。

### 第二阶段 专门训练蜱虫与非蜱虫复核

- 正例覆盖不同物种和目标区域；负例覆盖螨、蜘蛛、蚜虫、甲虫等混淆对象。只在训练集合挖掘检测误报裁剪，按来源划分，防止同图原图和裁剪进入不同集合。
- 在可用的预训练骨干上训练二分类复核器，先以现有ResNet-50作受控起点。模型选择依据验证集的蜱虫召回与非蜱虫误报，而非总准确率。
- 使用独立存在性证据与物种分类分工；28类物种softmax高，不意味着图片一定包含蜱虫。保留无复核器的基线，完整级联比较。

### 第三阶段 匹配部署区域的蜱种训练

- 从无冲突的物种图像准备原图与带上下文区域，统一训练和推理的方向、尺度和归一化。检测得到的区域只是辅助定位，不自动成为新的人工真值。
- 以现有448蜱种模型作对照，从ImageNet预训练权重重新训练（不用旧任务权重初始化，避免其已见过新的验证分组），对比整图与区域混合训练；按类别检查混淆、长尾和正确确认比例。
- 只有在数据和训练口径对齐后，才有必要比较更强或更适合的骨干；不同架构不能改变类别或样本后直接宣称准确率提升。

### 第四阶段 检测器重训与系统接入

- 使用同步增强、可信负例及相同尺度训练检测候选；通过真实验证结果选checkpoint，不默认最后一轮最佳。
- 顺序使用GPU，保存配置、seed、数据哈希、训练日志、最佳和末轮权重、验证预测及失败记录。旧权重不覆盖。
- 最终模型和阈值冻结后仅做验收，不用验收结果继续反复调参。达不到门槛的候选不替换默认模型，保留实验结论。

## 验收标准

以下是首轮选择目标，不是预先承诺已达到的指标。

- 非蜱虫图片产生蜱虫候选的比例，争取相对当前分支降低至少30%；同时蜱虫定位召回下降不超过2个百分点。两项必须一起报告，不能靠全部拒绝实现。
- 区域蜱种top1和macro-F1均检查；目标为同口径top1提高至少5个百分点，或在相近确认准确率下明显增加正确确认比例。减少类别、只筛简单图片或改变输出文案不能计为该提升。
- 固定展示各来源、蜱虫单只/多只、小目标、混淆虫、清晰/模糊的对照样本，按预定顺序给出原图、旧结果、新结果及失败案例，不能只挑成功图。
- 测量实际单请求耗时；离线批量吞吐不充当网页时延。组件、完整级联、历史回顾、新验收和未知物种必须分开报告。
- 如现有数据不足以支持28类可靠鉴别，保留类别和失败证据并明确指出限制，不能用接近随机的候选冒充确定蜱种。
