# 来源差异暴露后的复核策略修订

制定于2026-10-26，继续原识别重建任务。原模型与默认配置保留，不把一次代理误报改善当作整体成功。

## 新证据

run01最佳第12轮的存在性头在COCO目标区域上表现强，但对archive2近景蜱虫不足。检测val和calibration上的detector=.5、presence=.95通过代理误报与定位门槛；冻结109同源图却出现tick漏识别2→6、mite误报32→11。原策略不能默认上线。该109图现在已查看，后续只能作诊断/回顾，不能再次宣称未见验收。

新蜱种头未通过旧模型组件对照，继续保留原蜱种模型。旧模型见过新分组val/cal的部分来源，旧/新物种比较只能作诊断，不能视为公平未见评估。

## 修订步骤与预先约束

1. 读取此前尚未用于分类策略的完整calibration组件输出，按species_roi、COCO_roi、insect_tick_full分别检查蜱虫存在性。沿用已实现的binary_threshold函数：每个正例来源至少98%经验召回，取各来源允许门槛的最小值。小来源组不能被大来源组平均掩盖；不根据109图逐张调阈值。
2. 若降低存在性门槛导致明确昆虫误报，增加区域级粗分类一致性复核：仅非蛛形纲类别在其自身高置信门槛以上且存在性未达.95时否决该框。tick/mite/spider/spider_mite不执行这条粗分类否决；整图类别不能否决混合图片所有目标。每个模型检查自身条件，不比较不同softmax大小。
3. 该新策略仍须对完整检测val及完整分类val进行比较，报告按来源的存在性召回、代理误报和计数；检测calibration已查看，之后仅作开发核验，不再是全新确认集。原109图不用于阈值选择。
4. 后续新增验收必须来自既有项目数据的另一个预先冻结来源组，排除本轮训练/验证/校准及已查看109组，记录SHA和来源局限。若无法得到足够独立数据，明确标为回顾，不用措辞补齐证据。
5. 如新策略仍不能兼顾识出率与误报，优先保留原默认、将precision候选单独保留，继续按数据源分析训练问题。不得为了“已优化”而默认替换退步模型。

这是策略/评估修订，不新增外部数据，不覆盖原run01，不重写其失败证据。所有文档继续集中在本分支目录。
